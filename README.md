Unravel Data Systems is an AI-powered data observability and FinOps platform that helps data teams optimize performance, cost, and reliability across modern data stacks including Databricks, Snowflake, BigQuery, Amazon EMR, and Cloudera. The self-hosted and SaaS platform exposes a REST API (JSON over HTTP, session-token authentication via /signIn, RBAC-scoped) for querying application performance, cluster operations, chargeback, anomaly detection, and pipeline data collected by its observability engine.

**Areas:** Data Observability · FinOps · DataOps · Databricks · Snowflake · BigQuery · Cost Optimization · Performance

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Unravel Data Systems: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
